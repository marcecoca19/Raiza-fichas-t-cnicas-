Categorías de fichas ▾ tocá para editar

Estas son las categorías que agrupan Preparaciones base y Recetas (hechas a partir de las secciones de tu menú). Podés renombrarlas, quitarlas, agregar nuevas y cambiar el orden con las flechas.

Preparaciones base

Componentes reutilizables (una masa, una salsa, una proteína desmechada) que después se usan como ingrediente dentro de otras recetas. Cargá cuántas unidades produce el lote ("rinde") para que se calcule el costo por unidad.

Todavía no cargaste preparaciones base.

Control de stock

"Sincronizar ingredientes" trae al stock todo lo que esté en el catálogo de Ingredientes y todavía no esté acá. "Sincronizar productos terminados" trae todas las recetas cargadas en Fichas Técnicas (platos, pastelería, etc.) para controlar cuántas unidades tenés listas — por ejemplo Cheesecake o Carrot Cake. En ambos casos arrancan en cantidad 0 para que las completes; nombre, unidad y costo se calculan solos.
